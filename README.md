# MechaConvert – Smart Engineering Unit Converter

## What it does
MechaConvert is a Python-based engineering unit converter developed to simplify common engineering unit conversions. It converts between:
- Millimeters and inches
- Celsius and Fahrenheit
- Kilograms and pounds
- Kilometers per hour (km/h) and meters per second (m/s)

It also includes a conversion history and an engineering reference mode.

## How to run it
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python mechaconvert.py
```
